怎么用这份讲义

两种模式，按复习阶段切换。

MODE 1

自学模式

完整内容：直观说明 → 定义与定理 → 规范证明 → 例题 → 习题 → MIT 对照。首轮学习用这个。

MODE 2

刷题模式

点击章标题下的按钮，隐藏全部讲解与例题，只留题目。考前复习用，答案可一键展开。

NAV

目录两段跳转

侧栏每章可展开；每个知识点下有「知识点 / 练一练」两个入口，复习时直接跳到题。

MARK

进度标记

每个模块右上角有「已掌握」，勾选后侧栏出现绿点，状态保存在浏览器本地。

关于本讲义

说明

知识框架：按陈维新《线性代数》（第二版，科学出版社）的章节顺序编排，模块题头标注对应教材小节，便于对照上课进度与作业。

讲解与习题：全部重新撰写。目标是「准确 + 可独立消化」：定义与定理采用教材口径的表述，证明给出规范步骤，例题按「造零 / 降阶 / 递推」分类，习题按 ★ / ★★ / ★★★ 三档。

MIT 对照：链接指向 MIT OpenCourseWare 的 18.06 Linear Algebra（Gilbert Strang，2010 春），并附 B 站中文字幕版搜索入口。两套体系顺序不同：18.06 把行列式放在 L18–L20，先讲消元与四个基本子空间；本讲义按教材顺序推进。
